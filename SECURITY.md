# Security Policy

TracePulse monitors network devices and may be deployed in sensitive
environments. Please report suspected vulnerabilities privately so they can be
investigated before details are made public.

## Supported Versions

| Version | Supported |
| --- | --- |
| latest | :white_check_mark: |

Older versions are not guaranteed to receive security fixes. Please update to
the latest release before reporting an issue when possible.

## Reporting a Vulnerability

Please **do not report security vulnerabilities through public GitHub Issues,
Discussions, or Pull Requests**.

Use GitHub's [Private Vulnerability Reporting](https://github.com/traceworks-co-jp/trace-pulse/security/advisories/new)
feature for this repository. If that feature is unavailable, contact the
repository maintainers privately through the contact information listed in the
repository's GitHub Security settings.

Please include, when available:

- The affected TracePulse version or commit hash
- The type and impact of the vulnerability
- The affected component, configuration, or deployment mode
- Detailed reproduction steps or a proof of concept
- Any suggested mitigation or patch

We will acknowledge receipt within 48 hours when possible, assess the report,
and communicate the mitigation plan. Once a fix is ready, we will publish a
patch release or security advisory as appropriate, crediting the reporter when
they agree.
